# AI Daily Planner

Telegram-бот-планувальник: пишеш задачу звичайним текстом, бот сам
розуміє, що і коли треба зробити, і нагадує періодично — поки задачу не
відмічено виконаною.

> **Веб-кабінет: http://localhost:8010** (поки бот/кабінет запущені на
> комп'ютері). Логін/пароль — `WEB_ADMIN_USERNAME` / `WEB_ADMIN_PASSWORD`
> у файлі `.env`.

## Швидкий старт

```bash
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
cp .env.example .env           # і впишіть TELEGRAM_BOT_TOKEN

python run_bot.py
```

Якщо `ANTHROPIC_API_KEY` не задано, бот автоматично працює на легкому
регулярному розборі дати/часу (fallback) — усе працює й без ключа,
просто розпізнавання дедлайнів менш гнучке, ніж з живим ІІ.

## Як користуватись

Просто пишеш боту задачу:

> Подати документи в банк до завтра 15:00

або без дедлайну:

> Подзвонити сантехніку

Бот сам визначає, що робити і коли (якщо вказано), і починає нагадувати:
- з дедлайном — нагадування починаються з часу дедлайну;
- без дедлайну — нагадування починаються одразу, кожні 15 хвилин
  (`DEFAULT_REMINDER_INTERVAL_MINUTES` у `app/config.py`).

Кожне нагадування — з кнопками:
- ✅ Виконано — для разової задачі закриває її; для повторюваної —
  переносить на наступний цикл (наприклад, на завтра для "Щодня");
- ⏳ Ще ні — для разової задачі нагадає ще раз за той самий інтервал
  (`DEFAULT_REMINDER_INTERVAL_MINUTES`); для повторюваної — підпис на
  кнопці явно каже, коли саме нагадає знову ("до завтра", "на тиждень"
  тощо), і саме натискання цієї кнопки переносить нагадування на той
  момент — просто проігнорувати нагадування (нічого не натискати) для
  повторюваної задачі так само нагадає знову за звичайний короткий
  інтервал, як і для разової;
- 🔁 Перенести — наступне нагадування через годину (`SNOOZE_MINUTES`),
  незалежно від типу задачі.

Якщо те саме нагадування проігноровано `ESCALATION_THRESHOLD` разів
поспіль (за замовчуванням 5), тон наступних нагадувань змінюється.

Якщо в тексті задачі явно вказано періодичність — «нагадувати щодня» /
«напоминать ежедневно» / «щотижня» / «кожні 3 дні» — задача стає
повторюваною: після «✅ Виконано» вона не закривається назавжди, а
повертається на наступний раз (через день/тиждень/N днів).

Команда `/today` показує всі задачі на сьогодні — виконані, ще ні й
повторювані (🔁).

Не треба пам'ятати команди: поруч із полем вводу в Telegram є кнопка
"Menu" зі списком усіх команд (/new, /today, /tasks, /clear, /help).
Під кожним підтвердженням створеної задачі є також кнопка "📋 Усі задачі".

Під кожною задачею, де б вона не показувалась (нове підтвердження,
`/today`, `/tasks`), є кнопки:
- ✏️ Редагувати — проходить ту саму послідовність питань, що й `/new`
  (дедлайн, коли нагадати, періодичність), і оновлює задачу на місці
  (назва лишається та сама — для одруківки в назві простіше видалити й
  написати заново);
- 🗑 Видалити;
- ➕ Нова задача — щоб почати наступну, навіть якщо список довгий і
  кнопка вгорі списку вже не видно.

Якщо назбиралось багато тестових задач і хочеться почистити все одразу —
`/clear` видаляє геть усі задачі (і активні, і виконані) з підтвердженням
перед видаленням.

Якщо в одному повідомленні дві дати/часи (наприклад: дата самої події +
окремо вказано, коли нагадати) — бот бере ту дату, перед якою стоїть слово
на кшталт «нагадати»/«напомни». Якщо жодна явно не позначена — бот не
вгадує, а питає кнопками, яка саме дата потрібна.

Команда `/new` — покрокове створення задачі без жодного набору тексту для
дат/часу: що зробити (текстом) → дата дедлайну (календар, або «Без
дедлайну») → час дедлайну (години, потім хвилини) → «Коли нагадати?» —
тут одразу і тип повторення, і час: «📌 У дату дедлайну» (одноразово,
нагадає точно тоді ж, без повторного вводу дати), Щодня/Щотижня
питають тільки годину (старт одразу, повтор з того ж часу),
Щомісяця/своє число днів/«Інша дата і час» (одноразово) питають повну
дату через календар, бо для рідших повторень стартовий день важливіший.
Зручно для складних випадків, коли вільний текст може вийти
неоднозначним.

На кожному кроці майстра є кнопка "⬅️ Назад" — якщо випадково тапнули не
той пункт, можна повернутись на крок назад і вибрати інший варіант, без
набору тексту і без перезапуску `/new`.

## Веб-кабінет

Окремий процес (запускається поруч із ботом, не замінює нагадування в
Telegram — лише дає зручний огляд):

```bash
python run_web.py
```

Відкрий `http://localhost:8010` (порт — `WEB_PORT` у `.env`), вхід по
логіну/паролю (`WEB_ADMIN_USERNAME` / `WEB_ADMIN_PASSWORD`, за
замовчуванням `admin` / `change-me` — обов'язково зміни пароль).

Що є:
- таблиця всіх задач із фільтрами (Усі / Сьогодні / Прострочені /
  Повторювані / Виконані) і пошуком за назвою;
- редагування назви, дедлайну й періодичності прямо у формі;
- швидкі дії ✅ Виконано і 🗑 Видалити з таблиці або зі сторінки задачі.

## Структура проєкту

```
app/
  ai/           # розбір дедлайну з вільного тексту (Claude + regex fallback)
  services/     # бізнес-логіка задач та нагадувань
  bot/          # aiogram: команди, кнопки, фоновий планувальник нагадувань
  web/          # FastAPI-кабінет (дашборд, редагування)
  models.py     # модель Task
  db.py, config.py
tests/
run_bot.py
run_web.py
```
