# AI Daily Planner

Telegram-бот-планувальник: пишеш задачу звичайним текстом, бот сам
розуміє, що і коли треба зробити, і нагадує періодично — поки задачу не
відмічено виконаною.

## Швидкий старт

```bash
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
cp .env.example .env           # і впишіть TELEGRAM_BOT_TOKEN

python run_bot.py
```

Якщо `ANTHROPIC_API_KEY` не задано, бот автоматично працює на легкому
регулярному розборі дати/часу (fallback) — усе працює й без ключа,
просто розпізнавання дедлайнів менш гнучке, ніж з живим ІІ.

## Як користуватись

Просто пишеш боту задачу:

> Подати документи в банк до завтра 15:00

або без дедлайну:

> Подзвонити сантехніку

Бот сам визначає, що робити і коли (якщо вказано), і починає нагадувати:
- з дедлайном — нагадування починаються з часу дедлайну;
- без дедлайну — нагадування починаються одразу, кожні 15 хвилин
  (`DEFAULT_REMINDER_INTERVAL_MINUTES` у `app/config.py`).

Кожне нагадування — з кнопками:
- ✅ Виконано — задача закривається, нагадування припиняються;
- ⏳ Ще ні — бот просто нагадає ще раз за той самий інтервал;
- 🔁 Перенести — наступне нагадування через годину (`SNOOZE_MINUTES`).

Якщо те саме нагадування проігноровано `ESCALATION_THRESHOLD` разів
поспіль (за замовчуванням 5), тон наступних нагадувань змінюється.

Команда `/today` показує всі задачі на сьогодні — виконані й ще ні.

## Структура проєкту

```
app/
  ai/           # розбір дедлайну з вільного тексту (Claude + regex fallback)
  services/     # бізнес-логіка задач та нагадувань
  bot/          # aiogram: команди, кнопки, фоновий планувальник нагадувань
  models.py     # модель Task
  db.py, config.py
tests/
run_bot.py
```

## Наступні кроки (поки не зроблено)

- Веб-кабінет зі списком усіх задач (як у риелторського бота).
- Адаптивне планування часу нагадувань за історією.
